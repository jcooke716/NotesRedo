# Technical Foundations Reference Notes

A collection of introductory reference notes for reviewing computer fundamentals, Git, and Java before hands-on exercises or interview practice.

## What this repository provides

The files keep short explanations and command reminders together so foundational concepts can be reviewed without opening an application project.

| Document | Contents |
| --- | --- |
| [Computer Basics.txt](Computer%20Basics.txt) | Hardware, software, memory, and compilation versus interpretation. |
| [Git notes.txt](Git%20notes.txt) | Working directories, local and remote repositories, staging, commits, and remotes. |
| [Java Intro notes.txt](Java%20Intro%20notes.txt) | Java bytecode, the JVM, programming approaches, and development tools. |
| [Interview Questions Links.txt](Interview%20Questions%20Links.txt) | Reference links for Unix, Git, and Java questions. |
| [Look out.txt](Look%20out.txt) | Training expectations, project stages, and the original software checklist. |

## Use

Read the text files directly in GitHub or a text editor. There is no build or runtime requirement. Commands, tool versions, and schedules inside the notes are historical training examples and should be adapted to the current environment.

## Portfolio context and attribution

This is a learning reference collection, rather than an application or automation system. It is a fork of [DeveloperOneDemo/NotesRedo](https://github.com/DeveloperOneDemo/NotesRedo); the original training material and history are retained.
